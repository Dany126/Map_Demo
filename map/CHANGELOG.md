# Changelog

## 1.0.0

- Initial release of the `map` Flutter package.
- Clean Architecture implementation for OpenStreetMap with `flutter_map`.
- GPS location tracking and permissions.
- OSRM route calculation, polyline display, duration, and distance.
- Highly customizable configuration (`MapViewConfig`, `MapCameraConfig`, `MapTileConfig`, `MapRouteConfig`, `MapInteractionConfig`, `MapWidgetsConfig`).
- Controlled external camera access with `MapControllerActions`.
- Fully customizable builders for user marker, map markers, controls, route info, loading, error states, and bottom sheets.
